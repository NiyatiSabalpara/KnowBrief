# Frontend

The frontend is the React, TypeScript, and Vite client for AI News-to-Knowledge Converter.

For installation, API setup, supported features, and application usage, see the [project README](../README.md).

## Frontend commands

~~~bash
npm ci
npm run dev
npm run lint
npm run build
~~~

The Vite development server runs at http://localhost:5173 and proxies API requests to the FastAPI backend at http://127.0.0.1:8000.
